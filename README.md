# Overview

The **AI Investigation Details** widget shows the AI-driven investigation in the detail view of an alert record. It lists the investigation phases as they run, shows the hypotheses generated during triage along with the evidence that supports or weakens each, and displays the final verdict and summary once the investigation completes. From the widget, you can start a new investigation, re-run an investigation, and open the trace flow using the [**AI Agent Traceability**](https://github.com/fortinet-fortisoar/widget-ai-agent-traceability) widget.

> [!Note]
> This widget is part of the **FortiAI** solution pack - `v6.1.0` and later - and is installed with it. The widget triggers AI-powered alert investigations through playbooks and other platform services that the solution pack provides. Therefore, the widget requires the FortiAI solution pack to function.

For information, see the section **Performing AI Investigation** in [FortiAI](https://github.com/fortinet-fortisoar/solution-pack-fortinet-advisor/blob/release/6.1.0/docs/ai-investigation-details.md) solution pack documentation.
